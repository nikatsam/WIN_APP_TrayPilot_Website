TrayPilot lives in the Windows notification area. Start with the tray icon; if you like keyboard shortcuts, make that your front door instead.

01 / FIRST STEPS

Just want to use it?

  1. Install and launch TrayPilot from its Microsoft Store listing.
  2. Find its icon in the notification area near the Windows clock. Select it to open the flyout.
  3. Choose the control you need: display, audio, network, or one of the quick Windows actions.
  4. Click outside the flyout to dismiss it when you’re done.

No account or setup wizard is required. If Windows has tucked the icon away, open the notification-area overflow to find it.

02 / MAKE IT YOURS

Set a keyboard shortcut

The default global shortcut is Ctrl + Alt + Space. To change it:

  1. Open TrayPilot and select Keyboard shortcut at the bottom of its flyout.
  2. Choose Ctrl + Alt, Ctrl + Shift, or Alt + Shift, then a letter A-Z, Space, or F1-F11.
  3. Select Save shortcut to apply the new combination immediately.

Unsupported or already-reserved combinations are rejected, and the previous shortcut remains active. Turn off Show TrayPilot from anywhere and save to disable the global shortcut while keeping the tray icon available.

03 / DESK TUNER NOTES

More about the controls

Multiple monitors

TrayPilot discovers connected displays. Brightness over DDC/CI depends on the monitor, cable or dock, GPU, and driver. Some laptop panels support a Windows brightness fallback.

Refresh rate and HDR

Available refresh rates come from the modes Windows reports. HDR capability and state are informational only; HDR switching isn’t provided.

Audio endpoints

Select a playback endpoint and control speaker or microphone mute. TrayPilot does not route individual apps to different devices.

Network activity

Download and upload estimates use local adapter byte counters. They are aggregate speeds, not packet inspection or per-application usage.

04 / BEFORE YOU INSTALL

Requirements and privacy

TrayPilot supports Windows 11 version 22H2 (build 22621) or later. It does not support Windows 10. Hardware-dependent controls may be unavailable on some PCs without affecting the other controls.

TrayPilot requires no sign-in and has no cloud service or telemetry. It reads local system details needed for its controls; settings and diagnostics remain on the PC.
